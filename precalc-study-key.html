Domain and combining functions

Graded 0/1013 problems

How it works

  • Domain means every x you're allowed to plug in.
  • Two things break a function: dividing by zero and the square root of a negative. Throw out any x that causes either one.
  • Composition \((f\circ g)(x)=f(g(x))\). Put all of g(x) wherever f has an x.

Find the domain

Problems 1, 7, 9, 11, 17, 19, 21

1
\(f(x)=3(x-4)\)
  1. No fraction and no square root, so nothing can break.
Answer
\((-\infty,\infty)\), all real numbers
7
\(g(x)=\dfrac{3}{x^2-2x-15}\)
  1. Factor the bottom: \(x^2-2x-15=(x-5)(x+3)\)
  2. The bottom is 0 when \(x=5\) or \(x=-3\). Throw those out.
Answer
\((-\infty,-3)\cup(-3,5)\cup(5,\infty)\)
9
\(f(x)=\dfrac{1}{x+7}+\dfrac{3}{x-9}\)
  1. Two bottoms. \(x+7=0\) at \(-7\). \(x-9=0\) at \(9\).
  2. Throw out both.
Answer
\((-\infty,-7)\cup(-7,9)\cup(9,\infty)\)
11
\(g(x)=\dfrac{1}{x^2+1}-\dfrac{1}{x^2-1}\)
  1. \(x^2+1\) is never 0, because \(x^2\) can't be negative.
  2. \(x^2-1=0\) when \(x=1\) or \(x=-1\). Throw those out.
Answer
\((-\infty,-1)\cup(-1,1)\cup(1,\infty)\)
17
\(f(x)=\sqrt{x-3}\)
  1. What's under the root can't be negative: \(x-3\ge 0\)
  2. So \(x\ge 3\). 3 itself is fine because \(\sqrt0=0\).
Answer
\([3,\infty)\)
19
\(g(x)=\dfrac{1}{\sqrt{x-3}}\)
  1. Same root as #17, but now it's on the bottom, so it can't be 0 either.
  2. Need \(x-3\gt 0\), so \(x\gt 3\). This time 3 is out.
Answer
\((3,\infty)\)

\(g(x)=\sqrt{5x+35}\)
  1. \(5x+35\ge 0\)
  2. \(5x\ge -35\), so \(x\ge -7\)
Answer
\([-7,\infty)\)

33
\(f(x)=x-5,\quad g(x)=3x^2\)
  1. Add: \((x-5)+3x^2=3x^2+x-5\)
  2. Subtract: \((x-5)-3x^2=-3x^2+x-5\)
  3. Multiply: \(3x^2(x-5)=3x^3-15x^2\)
  4. Divide: \(\dfrac{x-5}{3x^2}\). The bottom is 0 at \(x=0\), so throw out 0.
Answer
ResultDomain

Plug one function into another

Find \((f\circ g)(x)\) and its domain. Problems 67, 68, 73

67
\(f(x)=\dfrac{2}{x+3},\quad g(x)=\dfrac{1}{x}\)
  1. Put \(\tfrac1x\) in for x in f: \(\dfrac{2}{\frac1x+3}\)
  2. Multiply the top and bottom by x: \(\dfrac{2x}{1+3x}\)
  3. Domain: g needs \(x\ne0\). The new bottom needs \(1+3x\ne0\), so \(x\ne-\tfrac13\).
Answer
\((f\circ g)(x)=\dfrac{2x}{1+3x}\), domain \(\left(-\infty,-\tfrac13\right)\cup\left(-\tfrac13,0\right)\cup(0,\infty)\)
68
\(f(x)=\dfrac{5}{x+4},\quad g(x)=\dfrac{1}{x}\)
  1. \(\dfrac{5}{\frac1x+4}\). Multiply the top and bottom by x: \(\dfrac{5x}{1+4x}\)
  2. Domain: \(x\ne0\) (from g) and \(1+4x\ne0\), so \(x\ne-\tfrac14\).
Answer
\((f\circ g)(x)=\dfrac{5x}{1+4x}\), domain \(\left(-\infty,-\tfrac14\right)\cup\left(-\tfrac14,0\right)\cup(0,\infty)\)
73
\(f(x)=x^2+4,\quad g(x)=\sqrt{1-x}\)
  1. \(f(\sqrt{1-x})=(\sqrt{1-x})^2+4=1-x+4=5-x\)
  2. Domain comes from g first: \(1-x\ge0\), so \(x\le1\).
Answer
\((f\circ g)(x)=5-x\), domain \((-\infty,1]\)

Trap: \(5-x\) looks like it works for every x, but g only allows \(x\le1\). Always check g before you simplify.

Dividing polynomials

Missing, was due 10/3013 problems

How it works

  1. Dividing by \(x-c\)? Write c in the box. For \(x+3\), use \(c=-3\).
  2. Bring the first number straight down.
  3. Multiply it by c, write the result under the next number, and add.
  4. Repeat to the end. The last number is the remainder. The others are the answer's coefficients, starting one power lower.

If a power is missing, put a 0 in its spot.

Remainder Theorem: the remainder from dividing by \(x-c\) equals \(f(c)\). A remainder of 0 means c is a zero and \(x-c\) is a factor.

Zeros and linear factors

Graded 0/2012 problems

How it works

  • Goal: find every zero, real and imaginary, then write f as (leading number) × \((x-\text{zero})(x-\text{zero})\cdots\)
  • Factoring moves: pull out what every term shares, group in pairs, use the cube formulas, or, when you only see \(x^4\) and \(x^2\), factor it like a normal quadratic with \(x^2\) in place of x.
  • Won't factor? Use the quadratic formula. A negative under the root gives \(i\): \(\sqrt{-a}=i\sqrt a\).
  • The degree tells you how many zeros to expect. A cubic has 3, and \(x^4\) has 4.

\(a^3-b^3=(a-b)(a^2+ab+b^2)\)\(a^3+b^3=(a+b)(a^2-ab+b^2)\)

Directions: find all zeros, then write \(f(x)\) as a product of linear factors.

1
\(f(x)=3x^3+x^2-2x\)
  1. Every term has an x. Factor it out (GCF): \(f(x)=x(3x^2+x-2)\)
  2. Factor \(3x^2+x-2\) with the ac method: \(a\cdot c=3(-2)=-6\). Find two numbers that multiply to \(-6\) and add to \(b=1\): \(3\) and \(-2\).
  3. Split the middle term: \(3x^2+3x-2x-2\)
  4. Group: \(3x(x+1)-2(x+1)=(3x-2)(x+1)\)
  5. So \(f(x)=x(3x-2)(x+1)\)
  6. Set each factor to 0: \(x=0\). \(3x-2=0\Rightarrow3x=2\Rightarrow x=\tfrac23\). \(x+1=0\Rightarrow x=-1\)
  7. Degree 3, so expect 3 zeros. Found 3 ✓
  8. Check \(x=\tfrac23\): \(3\cdot\tfrac{8}{27}+\tfrac49-2\cdot\tfrac23=\tfrac89+\tfrac49-\tfrac{12}9=0\) ✓
Answer
Zeros \(0,\ \tfrac23,\ -1\).  \(f(x)=x(3x-2)(x+1)\), or \(3x\left(x-\tfrac23\right)(x+1)\)
2
\(f(x)=x^3-9x^2+x\)
  1. Factor out the GCF x: \(f(x)=x(x^2-9x+1)\)
  2. \(x=0\) is one zero.
  3. Try to factor \(x^2-9x+1\): need two numbers that multiply to 1 and add to \(-9\). None are integers, so use the quadratic formula.
  4. \(a=1,\ b=-9,\ c=1\)
  5. Discriminant: \(b^2-4ac=(-9)^2-4(1)(1)=81-4=77\). \(77=7\cdot11\), which has no perfect-square factor, so \(\sqrt{77}\) stays.
  6. \(x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}=\dfrac{9\pm\sqrt{77}}{2}\)
  7. Check: the two roots should add to \(-\tfrac ba=9\). \(\tfrac{9+\sqrt{77}}2+\tfrac{9-\sqrt{77}}2=\tfrac{18}2=9\) ✓
  8. Each zero r becomes a factor \((x-r)\).
Answer
Zeros \(0,\ \dfrac{9+\sqrt{77}}{2},\ \dfrac{9-\sqrt{77}}{2}\)
\(f(x)=x\left(x-\dfrac{9+\sqrt{77}}{2}\right)\left(x-\dfrac{9-\sqrt{77}}{2}\right)\)
3
\(f(x)=3x^3+3x^2+x+1\)
  1. Four terms, so group in pairs: \((3x^3+3x^2)+(x+1)\)
  2. Factor each pair: \(3x^2(x+1)+1(x+1)\)
  3. Pull out the shared \((x+1)\): \(f(x)=(x+1)(3x^2+1)\)
  4. \(x+1=0\Rightarrow x=-1\)
  5. \(3x^2+1=0\Rightarrow3x^2=-1\Rightarrow x^2=-\tfrac13\)
  6. Square root both sides: \(x=\pm\sqrt{-\tfrac13}=\pm\dfrac{i}{\sqrt3}\)
  7. Rationalize: \(\dfrac{i}{\sqrt3}\cdot\dfrac{\sqrt3}{\sqrt3}=\dfrac{i\sqrt3}{3}\). So \(x=\pm\dfrac{i\sqrt3}{3}\)
  8. Leading coefficient is 3: \(3x^2+1=3\left(x^2+\tfrac13\right)=3\left(x-\tfrac{i\sqrt3}3\right)\left(x+\tfrac{i\sqrt3}3\right)\)
  9. Check \(x=-1\): \(3(-1)+3(1)+(-1)+1=-3+3-1+1=0\) ✓
Answer
Zeros \(-1,\ \pm\dfrac{i\sqrt3}{3}\)
\(f(x)=3(x+1)\left(x-\dfrac{i\sqrt3}{3}\right)\left(x+\dfrac{i\sqrt3}{3}\right)\)
4
\(f(x)=3x^3-6x^2+4x-8\)
  1. Group in pairs: \((3x^3-6x^2)+(4x-8)\)
  2. Factor each pair: \(3x^2(x-2)+4(x-2)\)
  3. Pull out \((x-2)\): \(f(x)=(x-2)(3x^2+4)\)
  4. \(x-2=0\Rightarrow x=2\)
  5. \(3x^2+4=0\Rightarrow3x^2=-4\Rightarrow x^2=-\tfrac43\)
  6. \(x=\pm\sqrt{-\tfrac43}=\pm\dfrac{2i}{\sqrt3}\)
  7. Rationalize: \(\dfrac{2i}{\sqrt3}\cdot\dfrac{\sqrt3}{\sqrt3}=\dfrac{2i\sqrt3}{3}\)

  9. Check \(x=2\): \(3(8)-6(4)+4(2)-8=24-24+8-8=0\) ✓
Answer
Zeros \(2,\ \pm\dfrac{2i\sqrt3}{3}\)
\(f(x)=3(x-2)\left(x-\dfrac{2i\sqrt3}{3}\right)\left(x+\dfrac{2i\sqrt3}{3}\right)\)

Rational functions and their graphs

Due Thu 11/5, 2:00 PM34 problems

How it works

  • Domain: throw out every x that makes the bottom 0.
  • Factor, then cancel. A factor that cancels makes a hole (an open circle). A factor left on the bottom makes a vertical asymptote, a wall the graph never touches.
  • Horizontal asymptote: compare the highest powers.
    • Bottom power bigger: \(y=0\)
    • Same power: divide the leading numbers
    • Top power bigger: no horizontal asymptote. If it's bigger by exactly 1, divide; the answer without the remainder is the slant asymptote.
  • \(x\to1^-\) means x creeping up to 1 from the left. \(x\to1^+\) means from the right.
  • Graphing in 7 steps: symmetry, y-intercept (plug in 0), x-intercepts (top = 0), vertical asymptotes, horizontal asymptote, a few points, draw.

Polynomial and rational inequalities

Due Fri 11/6, 1:00 PM15 problems

How it works

  1. Move everything to one side so the other side is 0.
  2. Factor. With fractions, combine into one fraction first.
  3. Find the critical numbers: where the top is 0 and where the bottom is 0.
  4. Put them on a number line and test one number in each piece.
  5. Keep the pieces with the sign you want.

Use \([\;]\) when the inequality allows "= 0" (\(\le\) or \(\ge\)). Never include a number that makes the bottom 0.

Don't multiply or divide both sides by something with x in it. You don't know if it's negative. Subtract instead.

On the number lines: + and − show the sign of each piece. A filled dot is included and an open dot is not.
