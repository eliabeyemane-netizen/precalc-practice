Using the TI-83 on Unit 2

Keys are in boxes. "2nd" means press the yellow 2nd key first.

Set up
Let it do \(i\) math (2.1)
  1. MODE, arrow down to the row Real a+bi re^θi, highlight a+bi, press ENTER.
  2. 2nd MODE (QUIT) to leave.
  3. The letter \(i\) is 2nd .
\[\begin{aligned}\texttt{(6-7i)(2+5i)}&\to 47+16i\\\texttt{5/(2-i)}&\to 2+i\\\texttt{√(-32)-√(-18)}&\to 1.414213562i=i\sqrt2\end{aligned}\]

Negative numbers use the (−) key next to ENTER, not the minus key.

Fractions
Turn a decimal answer into a fraction
  1. Type the problem, then MATH 1 (▸Frac) ENTER.
\[\begin{aligned}\texttt{6/(5+i)▸Frac}&\to \tfrac{15}{13}-\tfrac{3}{13}i\\\texttt{-16/3▸Frac}&\to -\tfrac{16}{3}\end{aligned}\]
f(c)
Plug a number into \(f\) (Remainder Theorem, testing \(\tfrac pq\))
  1. Y=, type the function next to Y1=. The \(x\) is the X,T,θ key.
  2. 2nd MODE (QUIT).
  3. VARS → arrow right to Y-VARS → 1 (Function) → 1 (Y1).
  4. Type the number in parentheses, then ENTER.
\[\begin{aligned}\texttt{Y1=2X^3-7X^2+9X-3}&\\\texttt{Y1(-13)}&\to-5697\\\text{Answer }0&\Rightarrow\text{that number is a zero}\end{aligned}\]
Table
Test many \(\tfrac pq\) values at once (2.5)
  1. Put \(f\) in Y1=.
  2. 2nd WINDOW (TBLSET): TblStart=-6, ΔTbl=.5.
  3. 2nd GRAPH (TABLE). Any row where Y1 is 0 is a zero.
\[\begin{aligned}\texttt{Y1=6X^3+X^2-4X+1}&\\X=-1&\to Y1=0\\X=.5&\to Y1=0\end{aligned}\]
Zeros
Find a zero from the graph (2.3, 2.5)
  1. Put \(f\) in Y1=, press ZOOM 6 (ZStandard).
  2. 2nd TRACE (CALC) → 2 (zero).
  3. Left Bound? Move the cursor left of the crossing, ENTER. Right Bound? Move right of it, ENTER. Guess? ENTER.
\[\begin{aligned}\texttt{Y1=X^3+9X^2+16X-6}&\to X=-3\ \text{(then long divide by }x+3)\end{aligned}\]

Use the graph to find a nice zero fast. The test still wants the division and the exact answer, like \(-3\pm\sqrt{11}\).

Max/min
Vertex of a parabola (2.2)
  1. Graph it, then 2nd TRACE → 3 (minimum) or 4 (maximum).
  2. Left Bound, Right Bound, Guess, each with ENTER.
\[\begin{aligned}\texttt{Y1=-2X^2+12X-16}&\to\text{Maximum }X=3,\ Y=2\end{aligned}\]

If the graph runs off the screen, press ZOOM 0 (ZoomFit).

Check
Check an inequality or asymptote answer (2.6, 2.7)
  1. Type the left side minus the right side in Y1=, with parentheses around every top and bottom: (X-6)/(X+2).
  2. GRAPH. For \(>0\) your answer is where the graph sits above the x-axis; for \(<0\), below it.
  3. For asymptotes, also put your slant line in Y2=. The graph should hug it at the edges.
